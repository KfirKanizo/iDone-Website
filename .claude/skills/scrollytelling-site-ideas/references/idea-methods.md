# Idea methods

## 1. Discovery lenses (write one line per lens before ideating)

| Lens | Question | Example (automation studio) |
|---|---|---|
| **Transformation** | What is the customer's state before → after? | Three disconnected vendors → one table |
| **Friction** | What hurts, concretely and visibly? | A lead sits unanswered for two days |
| **Mechanism** | How does it actually work, step by step? | Form → n8n → CRM → WhatsApp → invoice → report |
| **Proof moment** | What single moment makes the claim undeniable? | The message arrives seconds after the form is sent |
| **Mark** | What in the logo/name/colour can move or travel? | The dot in the "i" |
| **Time** | Does the offer have a visible duration or rhythm? | "Day 1 → day 7" for a site |
| **Scale** | Is there a number or size that can be felt physically? | One reel → a feed; one lead → a hundred at once |
| **Opposite** | What does the competitor's site do that we should refuse? | Stock photos, logo walls, feature grids |

## 2. Metaphor prompts

Complete these and keep the ones that surprise you:
- "Our work is like ____, because ____ happens in both."
- "If the page were a physical object, it would be ____ and scrolling would ____ it."
- "The customer's problem looks like ____ (tangled / scattered / stuck / late); the solution looks like ____ (aligned / connected / flowing / on time)."
- "The brand mark, if it could do one thing in each scene, would ____."

## 3. Through-line archetypes (pick, then make it specific)

| Archetype | Mechanic | Fits |
|---|---|---|
| **Travelling mark** (iDone dot) | A fixed element from the logo leaps between scenes and changes role (bullet, caret, play button, runner, orbit, walker, counter) | Brands with a simple mark; multi-service studios |
| **Thread / path** | One SVG line drawn by scroll that passes through every scene and becomes each scene's diagram | Process, logistics, integration, journey products |
| **Counter / clock** | A number or time that advances with scroll and explains each state | Speed, ROI, duration, deadlines |
| **Camera / zoom** | Scroll flies in/out of an abstract scene; zoom levels = layers (idea → UI → system) | Platforms, architecture, data |
| **Reveal / mask** | A boundary (cursor brush, split line, iris) reveals the "after" under the "before" | Redesign, restoration, creative work |
| **Assembly** | Scattered parts gather into an ordered whole as you scroll | Fragmented → unified claims |
| **Typing / authoring** | A caret writes the page, code, or message live | Software, writing, AI |
| **Pipeline / flow** | A lead/packet moves through stations, each lighting up | Automation, ops, fulfilment |
| **Orbit / loop** | Elements circulate; closing a loop completes a story | Ecosystems, "everything connects" |
| **Rail / ladder** | A walker climbs steps, each unlocking content | Methods, programmes, onboarding |
| **Light / reveal-by-light** | A beam or spotlight scans the page and illuminates the point being made | Security, clarity, quality |

## 4. Scroll mechanic menu (combine 3–5, not all)

Pinned scrub timeline · horizontal track · scene morph (wireframe → real UI) · stroke-draw path · count-up · split/before-after · sticky stack of cards · orbit · parallax depth (sparingly) · scroll-driven video frame scrub · cursor-follow reveal (desktop) · section-colour inversion (light ↔ ink) · text reveal by line/word.

## 5. Concept card checklist

A concept is ready only if:
- You can say the through-line in one sentence with a start and an end state.
- Every scene has a one-line message AND a visible mechanic.
- It only works for this brand (swap the name: does it break?).
- It has a payoff scene (usually the contact/CTA) that completes the through-line.
- There is a clear mobile/reduced-motion fallback.

## 6. Scoring rubric (1–5 each, show as a compact table)

| Criterion | 5 means |
|---|---|
| **Fit** | Could not belong to another brand |
| **Clarity** | The claim is understood within one scroll, without reading |
| **Wow** | A moment people would screenshot or describe to someone |
| **Buildable** | Standard GSAP/SVG/CSS; low risk; mobile fallback is easy |
| **Honesty** | No invented proof; abstract where real assets are missing |
| **Equality** | (brand-level) every offering carries equal weight |

Recommend the highest total, but break ties on Fit then Clarity. Flag cost separately ("most expensive: …").

## 7. Common traps

- Three concepts that are one idea in different words.
- A concept that requires a flagship client's product to make sense.
- A clever mechanic with no message ("scroll to see things move").
- Too many pins in a row; story longer than the offer deserves.
- Using the through-line as decoration instead of as the thing that *does* the work in each scene.
- Ignoring Hebrew/RTL: motion that "moves forward" must mirror.
